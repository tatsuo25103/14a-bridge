# V1.0.7

[English](RELEASE_NOTES_V1.0.7.md) · **繁體中文**

## 強化 OTA 回復

- 正式建置強制要求 ESP32 Bootloader Application Rollback 支援。
- 下載、簽章、大小、SHA-256、安全條件、分割區寫入或啟用驗證失敗時，
  保持目前韌體運行。
- 新版第一次開機的 15 秒驗證期間暫停所有逆變器 RS485 存取。
- 驗證前再次重啟、自檢失敗或無法標記有效時，自動回到上一個有效版本。
- 逆變器、PV、RS485、RSE、Wi-Fi 與 OTA 設定保存在 NVS。

## 本機回復

- OTA 成功後，以不可變的 ELF SHA-256 綁定上一個韌體分割區；過期或已被
  覆寫的紀錄會被拒絕。
- A+C 同時長按五秒；B 取消並鎖定，直到三個按鍵都放開。
- 只有在實體 RSE 穩定 100%、LIVE、Modbus 閒置且所有啟用逆變器達到目標
  時才可回復；不安全的要求不會重啟。
- 回復成功後關閉 AUTO OTA，避免立即重新安裝被拒絕的版本。
- LCD 顯示科技感圓形分段倒數、掃描點及大型秒數。

## 其他修正

- 沒有新版時回報 `AVAILABLE=-`，並保留簽章 Manifest 的診斷內容。
- 串列測試工具開啟 COM 時不再因 DTR/RTS 造成 ESP32 非預期重啟。
- 既有案場設定保持相容，新設備仍以 Strict 4-contact 為預設。

## 驗證

已在實機驗證 RSE 100/60/30/0%、ID3 10 kW 逆變器、簽章 OTA、故障注入、
自動與本機回復、B 取消、無備份情況、Windows 安裝檔及 GUI 自我測試。
