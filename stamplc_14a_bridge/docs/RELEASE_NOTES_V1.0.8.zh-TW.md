# 14a Bridge V1.0.8

## 新增功能

- 100%、60%、30%、0% 四段 RSE 功率可分別修改。初始值依 PV 裝機功率
  自動計算並受已驗證逆變器額定上限限制，裝機人員之後可輸入核准的整數或
  案場專用值。
- 每個 RSE 段位都有獨立的 **Feedin Enable** 選項。
- 新增 Schema 4 保存格式；Schema 1/2/3 的既有設備會自動遷移並保留原本
  的逆變器、Wi-Fi、RS485、RSE Profile 與 OTA 設定。

## 修改與修正

- 每次需要寫入 P17 暫存器 `0x04E5` 後都以 FC03 回讀確認，最多嘗試三次，
  不會無限重試。
- 三次功率驗證都失敗時，控制器會向 `0x0007` Bit 13 送出 P17 停止饋電
  指令 `0xDFFF`，並回讀確認 Bit 狀態。
- 正常控制時會先讀取 `0x0007`，只有確認目前狀態與 Feedin Enable 要求不同
  才寫入。若狀態無法讀取則保持不動；唯一例外是上述有限次功率寫入失敗後
  的安全停饋機制。
- Feedin Enable 關閉時，SmartPLC 與 GUI 顯示有效輸出 0 W，但 `0x04E5`
  仍依設定功率寫入；診斷欄仍保留原始暫存器回讀值。
- 定期健康檢查會唯讀確認功率及饋電允許狀態，不會反覆重寫未變更的數值。

> **運轉風險提醒：**修改 `0x0007` Bit 13 可能停止或重新啟動逆變器饋電。
> 每個 RSE 段位都必須由人員監督測試，且只能使用案場核准值。
